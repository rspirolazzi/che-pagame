# Contract: identidad visual (tokens, generador y tema)

**Feature**: `006-mobile-visual-identity`

No hay endpoints nuevos ni cambios en la REST API. Los contratos de esta feature son internos entre
la fuente de la identidad, sus salidas y quienes las consumen.

## 1. Generador `design/build-tokens.ts`

```text
node --experimental-strip-types design/build-tokens.ts [--check]
npm run tokens         (desde mobile/: escribe las salidas)
npm run tokens:check   (desde mobile/: no escribe; falla si algo no cumple)
```

| Situación | Sin `--check` | Con `--check` | Código de salida |
| --- | --- | --- | --- |
| Todo válido | Escribe las 3 salidas | No escribe | 0 |
| Falta o sobra un rol en `light` o `dark` | No escribe; lista los roles | Igual | 1 |
| Un valor no es `#RRGGBB` | No escribe; indica rol y modo | Igual | 1 |
| Un par no llega al mínimo | No escribe; una línea por par | Igual | 1 |
| Las salidas commiteadas difieren de lo que se generaría | — | Indica el archivo | 1 |

Formato de un error de contraste (una línea por par y modo):

```text
contrast: textMuted on surface (dark) is 3.92:1, minimum 4.5:1
```

## 2. `mobile/src/theme/tokens.generated.ts`

```ts
// Generated by design/build-tokens.ts from design/tokens.json. Do not edit by hand.
export const tokens = {
  color: { light: { primary: "#0B6FA8", /* ...14 roles */ }, dark: { /* ... */ } },
  contrastPairs: [{ foreground: "text", background: "surface", minimum: 4.5 }, /* ... */],
  typography: { brandFamily: "...", scale: { title: { size: 22, lineHeight: 28, weight: "700",
    family: "brand" }, /* ... */ } },
  spacing: { xs: 4, sm: 8, md: 12, lg: 16, xl: 24, xxl: 32 },
  radius: { sm: 8, md: 14, lg: 22, full: 999 },
  size: { touchTarget: 48 },
} as const;
export type ColorRole = keyof typeof tokens.color.light;
```

## 2b. `mobile/src/theme/tokens.generated.json`

Solo los colores (`{ "color": { "light": {...}, "dark": {...} } }`), para `app.config.ts`: el
cargador de configuración de Expo no puede importar módulos TypeScript. Agregado al implementar.

## 3. `web/src/styles/tokens.generated.css`

```css
/* Generated by design/build-tokens.ts from design/tokens.json. Do not edit by hand. */
:root { --color-primary: #0B6FA8; /* ...un --color-<rol-en-kebab> por rol */
  --space-xs: 4px; /* ... */ --radius-md: 14px; /* ... */ --font-brand: "<familia>", system-ui, sans-serif; }
@media (prefers-color-scheme: dark) { :root:not([data-theme="light"]) { --color-primary: #6CC4F2; /* ... */ } }
:root[data-theme="dark"] { --color-primary: #6CC4F2; /* ... */ }
```

No se importa en esta feature (la 007 lo conecta a `globals.css`).

## 4. Tema y hooks de Mobile

| Export | Firma | Comportamiento |
| --- | --- | --- |
| `lightTheme`, `darkTheme` | `AppTheme` | Colores MD3 mapeados según research R3; `custom` con los roles propios |
| `useAppTheme` | `(preference?: ThemeName) => AppTheme` | Igual que hoy: `system` sigue `useColorScheme()` |
| `useAppColors` | `() => AppTheme["custom"]` | Lee el tema activo con `useTheme<AppTheme>()` |

## 5. Componentes nuevos de Mobile

| Componente | Props | Garantías |
| --- | --- | --- |
| `AmountText` | `amount: string`, `currency`, `decimals`, `locale`, `variant?: "large" \| "regular"`, `subject?: "me" \| "other" \| "none"` | Color por signo (`positive`, `negative` o neutro), una insignia con "+", "−" o un tilde y nombre accesible ("A favor", "En contra", "Al día"), y el texto existente ("Te deben 60,00 ARS", "Debe", "Al día"...) sin cambios; con `none`, solo el importe. Cifras tabulares |
| `StatusNotice` | `kind: "warning" \| "error" \| "readOnly" \| "info"`, `children`, `action?` | Ícono + texto + color; `error` usa `accessibilityRole="alert"` |
| `Logo` | `variant: "full" \| "symbol"`, `size` | Elige la versión clara u oscura según el tema; `accessibilityLabel` "ChePagame" |
| `AppTabBar` | props de `Tabs` (`tabBar`) | `BottomNavigation.Bar` de Paper con Inicio, Cuentas y Perfil; activo con indicador y etiqueta; cada destino de al menos 48 dp |
| `AppButton` | props del `Button` de Paper + `tone?: "default" \| "danger"` | Alto mínimo `tokens.size.touchTarget` (48 dp); `danger` usa `theme.colors.error`. Las pantallas lo usan en lugar del `Button` de Paper |

## 6. Verificaciones automáticas (Jest, Mobile)

| Test | Falla cuando |
| --- | --- |
| `theme/contrast.test.ts` | Un par de `tokens.contrastPairs` no llega a su mínimo en algún modo |
| `theme/noHardcodedColors.test.ts` | Hay un literal de color en `src/` o `app/` fuera de `src/theme/`, o `accent` usado como color de texto (lista archivo y línea) |
| `components/touchTargets.test.tsx` | Un destino de la barra o un `AppButton` mide menos de `tokens.size.touchTarget` |
| `theme/appTheme.test.ts` | El mapeo a Paper no usa los valores de `tokens` (por ejemplo `primary`, `error`, `outline`) |
